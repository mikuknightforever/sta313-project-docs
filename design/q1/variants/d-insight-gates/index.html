Motivation. Decision-makers ask how caseloads moved around big public decisions. The federal income-support window (CERB, then CRB) and provincial OW and ODSP rule changes become gates in the cube, so an analyst sees what the path did between them, without a claim about cause.

Read this first: how to read the path

One dot per quarter

Across = ODSP cases, up = OW cases. Dots are joined in time order, from 2003 Q1 to the latest quarter. The optional 3D view adds time as depth; read exact values in the flat views or the panel on the right.

Direction means something

Moving right = ODSP grew; moving up = OW grew. Both axes use the same scale per index point (2019 Q4 = 100), so the dotted 45° line marks equal relative growth.

A case is not a person

A case can include a spouse and children. Counts are not adjusted for population. Province-wide OW counts include decimals in the source and are shown as published.
