This candidate changes one settled decision: the main view shows how fast each caseload changed (year-over-year %), not the number of cases. Reason: the question asks how the trends differed; change rates put both programs on one scale without an index. Case counts stay in the tooltips and in Figure 2.

Motivation. "Differ" is about direction and speed. Two change panels on one shared axis show where the programs agree and where they split.

Appeal. OW's plunge below zero in 2021 next to ODSP hugging the zero line; a strip that marks every quarter the two moved the same way.

Cost. Readers lose the size of each caseload in the main view; year-over-year change is noisier and needs a definition.

Read this first: what the numbers measure

Year-over-year change

Cases in a quarter compared with the same quarter one year earlier, in percent. Above zero = more cases than a year before; below zero = fewer. The first value is 2004 Q1.

Average annual change

For a whole period: (last ÷ first)1/years − 1. It makes periods of different lengths comparable. The group has not yet chosen a single growth-rate definition.

A case is not a person

A case can include a spouse and children. Counts are not adjusted for population. Province-wide OW counts include decimals in the source and are shown as published.

Pandemic period and context

March 2020 – May 2023 (2020 Q1 – 2023 Q1 in these data). The unemployment rate (monthly, Jan 2017 – Dec 2025) is context only.
