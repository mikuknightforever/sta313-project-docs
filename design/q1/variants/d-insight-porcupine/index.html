Motivation. Responsive planning depends on seeing turns early. A simple rule (continue the last two years' growth for two more) drawn as rays from the path shows where extrapolation works and where it breaks.

Appeal. A porcupine of rays: short and on target before 2018, then rays from 2019 and 2021 pointing the wrong way.

Cost. The rule is built here, not an agency's method; some rays leave the box (marked); misses depend on the two-year window.

Course basis. L2 derived data (rule forecasts, misses) · L3 misses as lengths and as a 2D error chart (Figure 1d) · L5 navigation (the slider picks the starting quarter) · L7 space-time cube: forecast trajectories in the same cube.

Read this first: how to read the path

One dot per quarter

Across = ODSP cases, up = OW cases. Dots are joined in time order, from 2003 Q1 to the latest quarter. The optional 3D view adds time as depth; read exact values in the flat views or the panel on the right.

Direction means something

Moving right = ODSP grew; moving up = OW grew. Both axes use the same scale per index point (2019 Q4 = 100), so the dotted 45° line marks equal relative growth.

A case is not a person

A case can include a spouse and children. Counts are not adjusted for population. Province-wide OW counts include decimals in the source and are shown as published.
