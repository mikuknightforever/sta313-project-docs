**已经用数据核实过的事实（可以直接用，但请自己重算一遍）：**
- 全省长期占比：2019Q4 是 55.2%，2021Q3 达到峰值 72.9%。

- 2026Q1 各 CMA 的长期占比：最高是 Peterborough 58.0%、St. Catharines–Niagara 55.6%、London 53.8%，最低是 Barrie 44.2%。

## 解释边界（必须遵守）

- 这个指标是**当前在册案件已经受助多久**的构成（存量），**不是**一次完整受助会持续多久，也不是个人以后会不会长期依赖援助的概率。题目里的 “duration of OW cases changed” 必须按这个意思解释，网站文字不能写成“人们领取援助的时间变长了”。
- 2021 年的峰值**只能**用数量和占比的关系来解释。不能写 CERB、新申请减少，或任何其他政策原因，现有数据没有直接证据。
- 0–4 个月这一档可以展示，但**不等于新申请人数**。
- 所有比较都是描述性的。不能推出因果关系、政策效果或者资源该怎么分配。
- “highest shares” 在单个季度的排名可能不稳定。请设计一种方式，让用户看到排名是不是长期稳定的（比如可以选季度，或者加 CMA × 季度热力图、某段时期的平均值）。

## 课程讲过的设计原则（逐条用上，并在设计说明里写明对应哪一讲）

**L1 什么是可视化 / L2 数据与任务抽象**
- 先写出数据抽象：时间是有序的数量型属性，时长档是**有序**属性（ordinal），CMA 是类别属性，案件数和占比是数量型属性。
- 再写出任务抽象，用课上的动词：Characterize distribution（时长构成）、Identify trend（随时间的变化）、Find extremum / Sort（哪些地区最高）、Compare（地区之间、地区和全省之间）、Retrieve value（查具体数值）、Find anomalies（2021 峰值）。
- 每个视图都要说明它服务于哪个任务。可以对数据做派生计算（占比、和全省的差值、时期平均），不一定直接画原始数据（课上说的 “Don't necessarily draw what you're given”）。

**L3 标记与通道**
- 遵守 **expressiveness**：时长档是有序的，所以不能用彼此无序的类别色相，要用亮度有序的色阶。CMA 是类别，不能用有序编码表示 CMA。
- 遵守 **effectiveness**：最重要的指标（长期占比）用最强的通道，也就是**共同基线上的位置**。不要让长期占比只能靠面积或颜色去读。
- 注意：100% 堆叠图中只有贴着基线的那一层能被准确比较。要么把“19 个月以上”放在基线上，要么提供单独的折线或小倍数图，让每一档都能单独比较。
- **Discriminability**：15 个 CMA 不要画成 15 条不同颜色的线。用课上讲的四种策略：空间编码、分组、过滤（filter）、分面（faceting / small multiples），再配合“选中的地区高亮，其余变灰”。
- **Separability / popout**：选中的 CMA 要能一眼跳出来（popout），用一个强通道，不要把几个通道混在一起。

**L4-1 感知与格式塔**
- 用**接近性**和**对齐**：多个视图共用同一条对齐的时间轴，放在一起。
- 用**相似性**：同一含义的东西在所有视图里用同一颜色。
- 用 **enclosure** 或 **connectedness**：说明时期范围的背景带，以及点和线的连接。
- 考虑自下而上和自上而下两种观看：先用最强的视觉元素引导视线看到关键发现，再提供细节。

**L4-2 颜色**
- 把颜色拆成亮度、饱和度、色相三个通道来考虑，不要笼统地说“用颜色表示”。
- 有序数据用单一色相的亮度变化（或 viridis 这类感知均匀的色阶），**禁止彩虹色阶**。
- 如果要展示“相对全省偏高还是偏低”，用发散色阶，中点设为全省值，中点用中性灰。
- 要求色盲安全，并用工具实际检查（比如 ColorBrewer 或对比度检查），浅色和深色主题都要检查。

**L5 交互**
- 按照 Card 等人的可视化流程（data → transformed data → visual mapping → view）说明每个交互改动的是哪一层。
- 至少覆盖这些交互方法，每个都要说清楚为什么需要：selection（悬停或点击选中 CMA，显示详情）、filtering（选时期、选时长档）、spatial arrangement（排序）、change mapping（比如在占比和案件数之间切换）、navigation（如果需要缩放时间范围）。
- 使用**多个联动视图**：在一个视图里选中，其他视图同步高亮或筛选。
- details-on-demand：悬停提示里必须显示季度、占比、**案件数**和全省对照值。
- 筛选控件只出现在适用的视图上（Q3 没有 ODSP，所以不出现项目切换）。

**L6 讲故事与沟通**
- 本项目同时需要 explanation（受众要得到明确的结论）和 exploration（分析员自己查地区）。建议用 **martini-glass 结构**：先展示带注释的关键发现（2021 峰值和地区排名），再开放自由探索。
- 采用 **annotated chart** 的形式：关键点直接标注在图上，写出 take-home message。
- 可以用的叙事模式：**contrast**（2019Q4 vs 2021Q3）、**juxtaposition**（数量图和占比图并排）、**repetition**（各 CMA 用同一套图形重复呈现，形成小倍数）。
- 有清晰的开头、中间、结尾：背景和定义 → 发现 → 用户可以带走的结论，以及能进一步调查的问题。

**L7 空间结构与地图**（如果要做地图）
- **不要用 choropleth**：CMA 的面积差别很大，大面积会被过度强调，小地区会被忽略，而且面积和案件数无关。
- 可以考虑：在 CMA 中心位置画比例符号（大小表示案件数，颜色表示长期占比），或者画 tile grid 地图，或者把地图仅仅作为选择地区的辅助小图。
- 投影要适合安省（比如 Lambert conformal conic）。边界数据在 `datasets/EXTERNAL/CMA-BOUNDARIES/`。
- 地图不能代替排序图来做精确比较。
