## 协作方式

1. 在对应目录新增或更新文档；也可以通过 GitHub 网页的 Add file / Edit 完成。
2. 提交说明写清本次修改，例如“补充两个研究问题”或“更新 Pitch 讲稿”。
3. 更新 [任务清单](TASKS.md)，把相关材料链接放在任务旁；在微信群通知组员。
4. 各负责人每两至三天同步一次进度，会后一天内确认自己的待办。
5. 重要方案调整由全组讨论，并记录决定及理由。

保留当前工作文档的稳定名称，修改历史由 Git 记录。正式归档文件使用 `任务名_YYYY-MM-DD_vN.ext`；课程最终提交文件保留教师规定的名称。
