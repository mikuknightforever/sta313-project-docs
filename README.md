# STA313 项目文书 / Project Documentation

STA313 小组项目的文书协作仓库，保存会议纪要、任务分工、研究问题、展示材料、贡献记录及教师公开课程数据快照。文档采用中英双语，会议纪要统一放在独立的 `meetings/` 文件夹。

This repository holds meeting minutes, task assignments, research questions, presentation materials, contribution records, and a snapshot of the instructor's public course datasets for the STA313 group project. Documents are bilingual in Chinese and English. All meeting minutes are kept in the dedicated `meetings/` folder.

## 协作方式 / How to Collaborate

1. 在对应目录新增或更新文档，也可通过 GitHub 网页的 Add file / Edit 完成。新增内容保留中英双语。<br>Add or update documents in the appropriate folder, using Git or GitHub's Add file / Edit interface. Provide both Chinese and English for new content.
2. 提交说明写清修改内容，例如“补充研究问题 / Add research questions”。<br>Use a descriptive commit message, such as “补充研究问题 / Add research questions”.
3. 更新[任务清单](TASKS.md)，补充成果链接，并在微信群通知组员。<br>Update the [task tracker](TASKS.md), link the work produced, and notify teammates in the WeChat group.
4. 各负责人每两至三天同步一次进度，会后一天内确认自己的待办。<br>Task leads share progress every two to three days; members confirm their action items within one day after each meeting.
5. 重要方案调整由全组讨论，并记录决定及理由。<br>Discuss major changes as a group and document the decision and rationale.

当前工作文档保留稳定名称，修改历史由 Git 记录。正式归档文件使用 `任务名_YYYY-MM-DD_vN.ext`；课程最终提交文件保留教师规定的名称。

Keep stable names for working documents and use Git to track revisions. Name archived versions `task_YYYY-MM-DD_vN.ext`; retain the instructor's required filenames for course submissions.
